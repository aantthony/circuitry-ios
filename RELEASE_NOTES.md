# Version 2.1 (build 303) release notes

- Build your own one-bit ALU in a new challenge covering AND, OR, XOR, and addition, with guided hints and carry handling.
- Fixed signal updates when one output connects to multiple gates.
- Improved stability and memory handling in large circuits.
- Fixed missing or outdated previews for saved circuits.
- Circuitry is now open source under the Apache 2.0 license, free to build and use at school, work, or home.
